# Rajan Chaudhary — Next.js Portfolio

A updated portfolio rebuild using the Next.js App Router with an SEO-first architecture.

## Why this version

- Server-rendered content by default.
- Centralized, editable profile/project data in `lib/`.
- Curated resume projects plus automatic public GitHub repository discovery.
- Project detail pages with per-page metadata and `SoftwareSourceCode` JSON-LD.
- Root `Person`, `WebSite`, and `ProfilePage` structured data.
- `sitemap.ts` and `robots.ts` generated by Next.js.
- Canonical URLs, Open Graph, Twitter card metadata, useful titles/descriptions, and semantic HTML.
- A grounded Gemini portfolio assistant using server-only API access and public profile data.
- No heavy animation library and no unnecessary state-management layer for a mostly content-driven site.

## Current stack

Next.js 16.3.5, React 19.3.0, TypeScript, CSS.

Current package versions were checked against npm on 12 September 2026.

## Run

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm start
```
